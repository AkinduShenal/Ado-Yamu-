# Ado Yamu! - 10-Screen iOS UI Image Pack

This pack splits the **same image mockup from the conversation** into separate screen PNGs.
No screen has been redesigned: colors, text, photography, layouts and appearance remain as displayed in that reference.

## Contents

- `01_Individual_Screens/` — 10 *exact pixel crops* of the original design, each including the iPhone frame.
- `02_3x_Preview_Screens/` — the same 10 screens enlarged 3x for reviewing and presentations. Enlarging does not create new detail.
- `03_Extracted_Images_and_Icons/` — 21 visible cropped scenic images, thumbnails, badges and mood icons from the original design. Some cropped areas retain UI overlays because the illustration is flattened.
- `04_Reference/` — original complete 10-screen design board.
- `Image_Assets_Manifest.csv` — origin and crop coordinates of each extracted asset.
- `index.html` — gallery; open locally in a web browser to view and access individual screen PNGs.

## Important for app development

This design was produced as **one flattened AI-generated mockup**. The original separate full-resolution destination photos, individual native icons and editable Figma/SwiftUI layers do not exist within that image. The extracted assets are pixel-accurate slices of what is visible, **not** original source photographs. Some are low-resolution or include labels and UI icons. For a shipped iOS app, you will want to replace these with licensed high-resolution imagery and implement native SwiftUI components.

The images and maps in the mockup are illustrative; geographic accuracy and real location information should be checked before shipping.
